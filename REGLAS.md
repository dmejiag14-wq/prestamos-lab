# Reglas de préstamos

El sistema administra laptops, proyectores y routers.

## Validaciones
- El nombre del solicitante debe tener al menos cinco caracteres.
- El carné debe cumplir el formato 0000-00-00000.
- La fecha del préstamo no puede ser anterior al día actual.
- El préstamo puede durar como máximo tres días.
- Cada estudiante puede tener un solo préstamo activo.

## Devoluciones
Al devolver un equipo, el préstamo deja de estar activo y el equipo vuelve a estar disponible.

## Préstamos vencidos
Los préstamos cuya fecha límite ya pasó se resaltan en la tabla para facilitar su identificación.
